# EconoCausal: Dynamic Pricing via Double Machine Learning

Internship-level Data Science & Machine Learning project for estimating the causal relationship between price and demand using **Double Machine Learning (DML)**.

## What it demonstrates
- Reproducible synthetic retail pricing data generation
- Exploratory data analysis
- Cross-fitted Double Machine Learning with Random Forest nuisance models
- Price elasticity estimation with uncertainty interval
- Model evaluation and out-of-fold predictions
- Interactive Streamlit demonstration
- Automated unit tests
- Internship-ready report and presentation source

## Run in VS Code
Use Python 3.11 when possible:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
```

Run the pipeline:
```powershell
python -m src.pipeline
```

Run tests:
```powershell
python -m unittest discover -s tests -v
```

Launch the dashboard:
```powershell
python -m streamlit run app.py
```

Or:
```powershell
.\run_project.ps1
```

## Validated results
The validated 8,000-row synthetic run produced:

| Metric | Result |
|---|---:|
| Estimated price elasticity | -1.1194 |
| Standard error | 0.0258 |
| 95% bootstrap interval | [-1.1650, -1.0714] |
| Outcome RMSE | 0.2438 |
| Outcome R² | 0.5456 |
| Treatment RMSE | 0.1005 |
| Treatment R² | 0.9817 |
| Observations | 8,000 |

The synthetic generator uses a benchmark elasticity of -1.25 only for controlled validation; it is not a real-market claim.
